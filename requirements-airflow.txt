# dbt-core and both adapters are pinned to the versions in requirements.txt.
# The schema.yml files use the `arguments:` syntax for generic tests, and an
# older dbt fails on it with "macro ... takes no keyword argument 'arguments'".
# Needs Python 3.9 or later; the Dockerfile's base image is python3.11.
#
# dbt's own dependencies (dbt-adapters, dbt-common, dbt-extractor, dbt-protos,
# dbt-semantic-interfaces) are left unpinned on purpose. This file is
# installed on top of the Airflow image in a separate pip run, and pinning
# them to the versions in requirements.txt ends in ResolutionImpossible.
# Unpinned, pip prints a warning about opentelemetry-proto and protobuf that
# can be ignored: no OpenTelemetry exporter is configured.
#
# apache-airflow-providers-postgres is not listed here. The Dockerfile
# installs it in its own step.
